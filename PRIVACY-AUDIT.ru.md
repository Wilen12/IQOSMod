# Аудит публичной поставки IQOSMod 3.0.6

Дата: 14 ноября 2026. Область: только перечисленные в PUBLIC-FILES.md файлы репозитория и assets стабильного и диагностического тестового Release, ZIP, ресурсы DLL и вложенные данные. Весь рабочий каталог разработки публиковать нельзя. Новая публикация автоматически не выполнялась. У Wilen12/IQOSMod есть один исходный коммит с коротким README; новых коммитов и Releases в ходе подготовки не создавалось.

## Результаты

- Приватные ключи, GitHub-токены, пароли и учётные данные в проверенных кандидатах не обнаружены. Проверялись распространённые форматы секретов, UTF-8/UTF-16, исполняемые строки .NET, вложенные ресурсы и совпадения с бинарными/текстовыми компонентами локального приватного ключа. Значения секретов не включались в отчёты.
- В публичном XML-ключе ровно Modulus и Exponent, RSA-3072. Параметры совпадают с публичной частью локального секретного ключа. Проверена detached-подпись manifest и SHA-256/размер каждого из 17 файлов подписанного пакета. Встроенные manifest/signature/archive Bootstrap совпадают с опубликованными рядом файлами.
- Имена учётных записей Windows, пользовательские email, личные IP-адреса и пути к компьютеру автора не обнаружены в очищенном содержимом. Пути PDB в метаданных зависимостей удалены. Пример пути к конкретной игровой установке не включён в документацию.
- Сохранения, player profiles, prefs, serveradmin, персональные конфигурации, игровые логи, дампы, скриншоты и результаты внутренних тестов не включены. Общий IQOSRouletteSettings.txt с настройкой диагностики является штатной конфигурацией мода, не настройками конкретного игрока.
- Исключены архивные .cs-исходники, старый .ps1-валидатор, внутренние QA-моды, отладочные файлы и бинарные QA-хуки Bootstrap. Доступ к HTTP loopback источнику и friend-assembly для QA из публичного Bootstrap удалены. Рабочие административные и калибровочные функции исходной IQOSMod.dll сохранены намеренно. Отдельный testing-пакет 3.0.7 намеренно содержит одну диагностическую строку журнала; он не является стабильным пакетом. Фикстура намеренной ошибки 3.0.8 остаётся локальной и не публикуется.
- Семь PNG проверены визуально и по структуре: нет EXIF/текстовых метаданных. Проверялись распакованные PNG-данные, сериализованные объекты и потоки обоих UnityFS AssetBundle, а не только сжатые байты ZIP.
- Ни один файл не отправлялся на внешние сервисы анализа. Аудит выполнен локально; исходники, ключ, журналы и сырые результаты остались вне публичной папки.

## Очистка и повторная проверка

Предыдущие непубличные установочные архивы включали архивные исходники/тестовый скрипт и пути PDB поставщиков. Они не изменялись и не входят в эту папку. Для публичной копии создан новый подписанный начальный пакет без этих файлов. Игровая IQOSMod.dll, игровые XML, материалы/анимации/пар и иконки сохранены побайтно.

Bootstrap и Gate пересобраны только в отдельной публичной копии: удалены QA-входы, встроен очищенный подписанный пакет, исключены ненужные Scripts/Tests-ссылки фасада. Изменения зависимостей и их статуса strong-name раскрыты в THIRD-PARTY-NOTICES.txt. Повреждённая или недействительная подпись поставщика не выдаётся за корректную.

Для интеграции официального репозитория в копии очищенного Bootstrap изменена только строка Repository по умолчанию на Wilen12/IQOSMod. Stable-пакет 17 файлов, его подпись и закреплённый публичный ключ не менялись. Стабильная игровая IQOSMod.dll не пересобиралась.

Очищенная основа проверена в настоящем отдельном Local/None-клиенте без EAC и защищённых серверов: один Runtime, один Gate, загрузка игровых XML/Prefab, native-перезарядка и расход HEETS, стимуляция, полный перезапуск и смерть/возрождение с сохранением зависимости. Для привязанного репозитория дополнительно проверены реальное чтение пустого списка GitHub Releases без уведомления, запрет повторной установки той же версии и локальное применение/откат подписанных фикстур только до меню. Активная установка и замороженный Stable Candidate не менялись. Настоящее скачивание assets с GitHub проверяется после согласованной публикации; локальные фикстуры за него не выдаются.

## Что не является личными данными

В зависимостях сохраняются общеизвестные технические строки: версии .NET-сборок, названия публичных библиотек, URL GitHub и шаблон системного временного файла Linux в Harmony. Такие строки не являются email/IP/путями к компьютеру автора. Они не удалялись путём произвольного изменения рабочего кода зависимостей. Числа вида версии сборки не считались IP-адресами автоматически.

Сигнатурный поиск по произвольным сжатым и пиксельным данным даёт случайные совпадения; результаты сопоставлены с декодированными метаданными и форматами. Это аудит конкретной поставки, а не доказательство отсутствия любого возможного скрытого или зашифрованного сообщения. Целевые проверки не обнаружили секретов или личных данных, требующих остановки по условию владельца.

Эти материалы отсутствуют здесь. Публикуйте только этот заранее проверенный набор и отдельно проверяйте любые будущие дополнения.
