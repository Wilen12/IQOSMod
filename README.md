# IQOSMod

IQOSMod 3.0.6 для **7 Days to Die V3.4.0 (b10)**, Windows x64, Unity 2022.3.62f2. Многоразовый IQOS3 DUO, HEETS, Nicotine Roulette, зависимость, ломка и восстановление, собственная модель, анимации и объёмный пар.

Официальный репозиторий: [Wilen12/IQOSMod](https://github.com/Wilen12/IQOSMod). Установочные архивы находятся в [GitHub Releases](https://github.com/Wilen12/IQOSMod/releases). Полная инструкция — [README.ru.md](README.ru.md).

## Установка

1. Закройте игру. Сохраните прежние папки мода вне всех каталогов Mods. Старую и новую установки не объединяйте.
2. Из стабильного релиза скачайте `IQOSMod_3.0.6_Windows_Public.zip`. Скопируйте обе папки из его `Mods` в `Mods` игры: `00_IQOSBootstrap` и `IQOSMod`.
3. Запускайте игру **без EAC**, отключив его штатным launcher. Не подключайтесь к серверам с EAC. Мод не обходит античит.
4. Проверьте F1 → `iqosupdate status`: версия 3.0.6, readyTrue, repository Wilen12/IQOSMod.

Для работы обновлений не нужны отдельный EXE, PowerShell или сторонний лаунчер. Оригинальные игровые файлы и сохранения не заменяются. Обновление Runtime и данных выбирается при следующем запуске игры; во время сессии загруженная DLL не перезаписывается.

## Подписанные обновления

Новая установка уже использует `Wilen12/IQOSMod` и канал `stable`. Проверка запускается из мода автоматически и вручную через `iqosupdate check`. Клиент использует публичный API Releases и не требует GitHub-токена или учётной записи.

Если ранее устанавливалась сборка 3.0.6 с пустым адресом репозитория, сохранённая настройка сохраняется. Однократно выполните:

```text
iqosupdate repository Wilen12/IQOSMod
iqosupdate channel stable
iqosupdate enabled on
iqosupdate check
```

Версия 3.0.6 не обновляется сама на себя. Новее должны быть и номер версии, и монотонный sequence. Пререлизы с каналом testing обычный stable-клиент игнорирует.

Manifest подписан RSA-3072/SHA-256. Проверяются подпись, хеш и размер каждого файла, версия игры и контракт сохранений/сети. Закреплённый публичный ключ: [release-public.xml](release-public.xml). SHA-256 ключа:

```text
50505DC723E2591B75B8AAB654A44B54F90DBB1C1FEE631C1855A1ABD13F2E07
```

Приватный ключ никогда не входит в репозиторий, клиент или Release. При ошибке обновления остаётся предыдущая проверенная версия. При ошибке запуска новой Runtime мир блокируется; следующий запуск выполняет откат. Игра не перезапускается автоматически. Узкий аварийный отказ защиты может завершить только текущий процесс до появления мира.

## Сетевая игра и тестовые версии

Перед сетевой игрой согласуйте версию с сервером и включите `iqosupdate multiplayer on`. Применение подготовленного пакета подтверждается через `iqosupdate apply` в главном меню и требует нового запуска. Это не автоматическое согласование полного набора модов с сервером. Двухклиентная проверка Steam ещё не завершена.

Testing предназначен для отдельной копии игры и отдельного UserData. Порядок проверки настоящего скачивания и отката описан в [TEST-PLAN.ru.md](https://github.com/Wilen12/IQOSMod/blob/main/TEST-PLAN.ru.md). Диагностический prerelease3.0.7 меняет только версию ModInfo и одну строку журнала при инициализации; игровые формулы и анимации сохранены. Обычным игрокам следует оставаться на stable.

## Конфиденциальность и зависимости

Публикуется только очищенный набор: [аудит](PRIVACY-AUDIT.ru.md), [полный перечень](PUBLIC-FILES.md). Сохранения, персональные настройки, логи, дампы, внутренние тестовые инструменты и исходники не включены. Метаданные зависимостей очищены от PDB-путей; изменённый статус библиотек раскрыт в [уведомлении](https://github.com/Wilen12/IQOSMod/blob/main/LICENSES/THIRD-PARTY-NOTICES.txt). Лицензии Harmony и Mono.Cecil сохранены в LICENSES репозитория и внутри папки Bootstrap клиентского архива.

Совместимость ограничена указанной сборкой игры. Dedicated server, Linux/Proton и другие версии игры отдельно не сертифицированы. Замена самого Bootstrap или ключа требует новой доверенной установки.
