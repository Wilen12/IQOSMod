# IQOSMod 3.0.6 — публичная поставка

Для 7 Days to Die V3.4.0 (b10), Windows x64, Unity 2022.3.62f2. EAC должен быть выключен штатным способом. Не используйте эту сборку на серверах с EAC. Обход античита не выполняется.

## Установка

Полностью закройте игру. Сохраните старые папки IQOSMod и IQOSBootstrap вне всех каталогов Mods. Затем скопируйте обе папки из поставляемого Mods в Mods игры. Старую и новую установку не объединяйте: в корне фасада не должно остаться прежней IQOSMod.dll. Альтернативно используйте клиентский IQOSMod_3.0.6_Windows_Public.zip с той же структурой Mods.

При первом запуске Bootstrap сам извлечёт встроенную подписанную версию в отдельное хранилище UserData. Отдельный лаунчер, внешний процесс и PowerShell для работы обновлений не нужны. В консоли F1 выполните `iqosupdate status`: ожидается version3.0.6 и readyTrue. Сохранения, внутренние имена предметов и CVars не переименованы.

Игровая IQOSMod.dll, XML, модель, анимации, пар и семь иконок сохранены без изменения содержимого. Из вложенного пакета исключены архивные C#-исходники, старый тестовый скрипт и неиспользуемый маркер сборки. Значения штатной конфигурации мода сохранены; это общая конфигурация, не личные настройки игрока.

## Обновления

Официальный репозиторий — [Wilen12/IQOSMod](https://github.com/Wilen12/IQOSMod). Его адрес уже встроен в новую установку; клиент не требует GitHub-токена или пароля. При ранее сохранённой пустой настройке репозитория однократно выполните:

```text
iqosupdate repository Wilen12/IQOSMod
iqosupdate channel stable
iqosupdate enabled on
iqosupdate check
```

Используются публичные GitHub Releases. Manifest подписан RSA-3072/SHA-256; публичный ключ закреплён в Bootstrap. Проверяются каждый файл, версия игры, контракт сохранений/сети и последовательность релиза. Скачивание и проверка обновлений выполняются в фоне. Новая Runtime выбирается только при следующем запуске процесса. Сообщение об успешной установке появляется после подтверждённой загрузки новой версии. При отсутствии обновления уведомления нет; недоступность GitHub не мешает офлайн-игре.

Для сетевой группы заранее включите `iqosupdate multiplayer on`, согласуйте версию с сервером и друзьями. Подготовленная версия требует одноразового `iqosupdate apply` в главном меню и нового запуска игры. Во время мира Runtime не заменяется. Полный двухклиентный тест ещё не выполнен. Для отключения автоматических обновлений используйте `iqosupdate enabled off`.

Игра не перезапускается автоматически. Единственный аварийный случай: при невозможности установить защиту запуска завершается только текущий процесс до появления мира. После ошибки инициализации новой Runtime мир блокируется, а следующий запуск выполняет откат. Если повреждены постоянные Bootstrap/Gate, восстановите обе папки из клиентского ZIP при закрытой игре. Удаление мода — перенос обеих обычных корневых папок вне Mods; игровые сохранения не удаляйте. Не удаляйте рекурсивно цели внутренних junction вручную.

Автообновление распространяется на Runtime и данные в текущем API-контракте. Смена самой игры, Bootstrap или ключа требует новой доверенной установки. Хранилище обновлений находится в UserData; точный путь для своей установки можно получить через `iqosupdate status`. Требуются локальная NTFS и права записи в свои папки мода и UserData.

## Состав публичных файлов

Полный перечень файлов репозитория и assets каждого Release, включая ZIP и встроенный пакет DLL, приведён в PUBLIC-FILES.md. Каждый Release имеет свой SHA256SUMS.txt. Эти хеши проверяют целостность копирования; подлинность обновления проверяется отдельной криптографической подписью manifest.

Для стабильного GitHub Release v3.0.6 предназначены:

- IQOSMod_3.0.6_Windows_Public.zip — установка пользователем.
- iqosmod-stable.manifest.json, iqosmod-stable.manifest.sig, iqosmod-stable.zip — три согласованных файла начального подписанного выпуска.
- release-public.xml и SHA256SUMS.txt — публичный ключ и контрольные суммы assets.

Начальная версия 3.0.6 не считается обновлением для уже установленной 3.0.6. Следующий реальный выпуск требует большей версии и sequence. Ранее подготовленные непубличные диагностические архивы публиковать вместе с этой поставкой нельзя. Ничего не опубликовано автоматически.

Публичный ключ содержит только Modulus и Exponent. Его SHA-256: `50505DC723E2591B75B8AAB654A44B54F90DBB1C1FEE631C1855A1ABD13F2E07`. Секретный ключ должен оставаться только у издателя, вне репозитория и Release.

## Проверки и ограничения

Проверены подпись и все 17 файлов начального пакета, метаданные пяти DLL, вложенные ресурсы/архивы, два AssetBundle, семь PNG, XML и ссылки на классы. Очищенная основа отдельно запущена в изолированном Local/None-клиенте без EAC: штатная перезарядка, использование HEETS, стимуляция, сохранение, повторный запуск и смерть/возрождение прошли. Привязка репозитория меняет только значение Repository по умолчанию, игровые файлы сохраняются. Это не новая художественная оценка анимаций и не сертификация мультиплеера.

Политика проверки подлинности не ослаблялась. Изменения метаданных двух зависимостей явно описаны в Mods/00_IQOSBootstrap/THIRD-PARTY-NOTICES.txt внутри клиента и LICENSES в репозитории. Подробности конфиденциальности — PRIVACY-AUDIT.ru.md. Адрес API Releases доступен. Проверка настоящей загрузки новых assets и отката через GitHub выполняется после согласованной публикации тестового Release; она не подменяется локальной фикстурой.
